# @deckio/deck-engine v1.17.3

**Released:** 2026-05-18

## What changed

### Fixed

- **Stop teaching `flex: 1` on the EditableList container.** The v1.17.2
  example in `inline-editing.instructions.md` showed the grid class
  with `flex: 1; min-height: 0; align-content: start`. That made the
  grid stretch to fill the slide's `.body` flex column, which defeated
  the longstanding `.body { justify-content: center; flex: 1 }` rule
  that vertically centers content. The result: new slides rendered
  with cards pinned to the top of the canvas and a giant empty band
  below — the very opposite of the "out-of-the-box centered" baseline
  the harness used to produce.
- Restored the historical pattern: the EditableList container is a
  content-sized block; `.body`'s `justify-content: center` centers it.
  Added a `do NOT add flex: 1 here` comment to the example so this
  doesn't regress again.

## Upgrade guide

No code changes required. Bump and rebuild:

```sh
npm install @deckio/deck-engine@^1.17.3
```

Pair with `deck-launcher` ≥ 0.2.2 for the matching system-prompt fix.
If you have existing decks scaffolded under v1.17.2 docs and your
generated slides have `flex: 1` on the EditableList grid class,
remove that line to restore vertical centering.
