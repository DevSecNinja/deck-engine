# @deckio/deck-engine v1.17.0

## Minor Changes

### Inline text styling

`<Editable>` now supports inline style overrides — font family, font size,
weight, color, alignment, transform — managed via a floating dev-only
toolbar that anchors itself to the field you're editing. The toolbar
shows theme tokens (`var(--accent)`, `var(--font-display)`, …) first and
exposes an "Advanced" disclosure for free hex colors. Styles persist in
`src/data/inline-edits.json` alongside text overrides and apply in BOTH
dev and inert rendering.

```jsx
// Author code is unchanged — styling just works in dev.
<Editable as="h1" id="cover.title">{cover.title}</Editable>
```

### Drag-and-drop list reorder

New `<EditableList>` primitive lets users reorder list items inside
slides by dragging. Reorders persist via the same inline-edit pipeline
that handles text. Reorder is a dev-only capability; production renders
the saved order without loading any drag-and-drop code.

```jsx
<EditableList id="features.items" items={features} keyOf={(f) => f.id}>
  {(feature) => <FeatureCard {...feature} />}
</EditableList>
```

The 6 bundled generic slides (`GenericAgendaSlide`, `GenericGoalsSlide`,
`GenericObjectiveSlide`, `GenericStepsSlide`, `GenericTocSlide`,
`GenericTwoOptionsSlide`) have all been converted; their sample data
arrays gained explicit `id` fields so reorder is stable. User decks that
pass arrays without `id` fields render in source order and log a
dev-only warning — they are not broken.

### Bundle cost

`EditableList.jsx` is a prod-safe shell that imports zero drag-and-drop
code. The sortable variant (`EditableListSortable.jsx`) is loaded via
`React.lazy(() => import('./EditableListSortable.jsx'))` inside a
dev-only branch, so Rollup splits `@dnd-kit/core` + `@dnd-kit/sortable`
into a dev-only chunk that production never requests.

### Storage schema

`inline-edits.json` extends from `{ field → string }` to typed entries
discriminated by shape:

```jsonc
{
  "cover.title":    "Welcome",                                  // bare string (back-compat)
  "cover.subtitle": { "value": "Hello",
                      "style": { "color": "var(--accent)" } },  // text + style
  "features.items": { "order": ["pricing", "speed", "quality"] } // reordered list
}
```

Bare-string entries continue to load unchanged; new shapes are validated
on both client and server with strict per-key normalizers (color, font,
size are bounded; URL/JS injection patterns are blocked).

### New exports

- `EditableToolbar`
- `EditableList`
- `useOrderedItems(fieldId, items, getId)`
- `useInlineEditEntry(fieldId)`

### Dependencies

Adds `@dnd-kit/core@^6.3.1` and `@dnd-kit/sortable@^10.0.0`. Both are
loaded only by the dev-only sortable chunk and have no production cost.
