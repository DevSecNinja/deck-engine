# @deckio/deck-engine v1.22.1

**Disclosure slides no longer export washed-out.** A follow-up to v1.22.0: fixes
progressive-disclosure slides exporting at reduced opacity (a dim, half-faded
look) compared to the rest of the deck.

Applies to **PDF and PowerPoint** alike (shared `captureSlidePng` path).

## What was wrong

v1.22.0 made hand-rolled disclosure slides export *revealed* (the export pump
synthesizes forward keys until the slide stops mutating). But a reveal is an
animated transition — e.g. `.deck-steps-step` fades `opacity: 0.15 → 1` over
**0.5s**. The pump triggers those transitions immediately before capture, and the
exporter then *paused* animations in place. So just-revealed elements were frozen
**mid-transition** and rasterized at partial opacity → the disclosure slide
looked muted/ghosted next to fully-opaque slides.

This was class-name agnostic in cause: the export-mode CSS that snaps the
engine's own `.deck-steps-step` to `opacity: 1` can't know a hand-rolled slide's
reveal classes, so those slides slipped through.

## Fix

`pauseAnimations` now **settles motion** instead of merely pausing it. Via the
Web Animations API (`getAnimations({ subtree: true })`) it:

- **finishes finite** animations and transitions — snapping any in-flight reveal
  to its final, fully-revealed state (full opacity, final transform), and
- **pauses only infinite** decorative loops (orbs, glows) at their current frame
  for a clean still.

Because it operates on the live animation timeline rather than specific CSS
selectors, it fixes **any** disclosure slide — engine-built or hand-rolled —
without per-deck wiring. Falls back to the previous play-state freeze where the
Web Animations API is unavailable.

## Validation

- Engine test suite: **722 passing** (added an export-wiring regression asserting
  finite animations are finished and only infinite loops paused).
- Re-verified with the Playwright export harness against a real deck: both
  progressive-disclosure slides (a 3-node timeline and a 14-row comparison)
  export at full opacity, matching the live app — and the gradient-clipped
  "Thank You" headline still exports visible (no regression from v1.22.0).
