# create-deckio v0.4.0

## What changed

### Added
- Add `--no-install` and `DECKIO_SKIP_INSTALL=1` support so hosts with shared dependencies can scaffold deck files without running a per-project `npm install`.

### Changed
- Initialize Copilot skills, instructions, memory, eyes, and VS Code settings from a shared `@deckio/deck-engine` install when dependency installation is skipped.

## Upgrade guide

Existing `create-deckio` usage is unchanged. Use `--no-install` only when another runtime links or installs dependencies before starting the deck.
