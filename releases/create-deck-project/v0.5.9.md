# create-deckio v0.5.9

**Dependency refresh** — newly scaffolded (and composed) decks now pin
`@deckio/deck-engine` to **`^1.22.0`**, picking up the export-fidelity fixes
(gradient-clipped text incl. editable headlines, progressive-disclosure reveal,
custom-badge breathing room), the new export-safe `useDisclosure` hook, and the
`deck-add-disclosure` skill + `progressive-disclosure` instructions.

## What changed

- Bumped the bundled `deckio.engineVersion` from `^1.18.0` to `^1.22.0`. This is
  the engine range stamped into a new deck's `package.json` when the scaffolder
  runs from a published install (i.e. the hosted runtime), so fresh decks now
  declare a current engine range instead of a stale one.

Local-workspace scaffolds are unaffected: they already resolve a `file:` link to
the monorepo engine source.
